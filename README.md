### ❤️ Cardiovascular Disease Risk Prediction
`Python` · `Pandas` · `NumPy` · `Scikit-learn` · `Matplotlib` · `Seaborn`

Binary classification system predicting heart disease presence from a 303-patient clinical dataset (13 features).

- 🔍 **EDA:** Visualized correlation heatmaps, sex-wise disease distribution, and age vs. heart rate analysis.
- ⚖️ **Benchmarking:** Evaluated KNN, Random Forest, and Logistic Regression baseline performance.
- 🎯 **Hyperparameter Tuning:** Tuned Logistic Regression via `GridSearchCV` → **75.4% test accuracy, 82.8% CV accuracy** (7-fold).
- 📈 **Evaluation:** Precision 81% · Recall 89% · F1-Score 85% with ROC/AUC evaluation.
- 🧩 **Feature Importance:** Identified `sex` and `thal` as primary negative predictors, and `cp` (chest pain type) as the primary positive predictor.
